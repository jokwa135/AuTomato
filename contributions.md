# Contributions and contributors

## Contributors

- **AuTomato maintainer**: product direction, design feedback and project ownership.
- **Codex (OpenAI)**: AI-assisted implementation, interface development, CLI integration, regression testing, packaging and release preparation under the maintainer's direction.
- **HKUDS CLI-Anything contributors**: upstream REPL skin used by the optional CLI; see the third-party notices and Apache-2.0 license.

## Contributing

Open an issue describing the problem or proposed improvement before a large
change. For a fix, include reproduction steps, the expected behavior and a
focused regression check. Submit a pull request with a clear description and
the validation you performed. Follow the setup and test instructions in README.md.

Keep browser profiles, cookies, passwords, tokens, personal assets, downloaded
media, local paths and generated output out of commits and screenshots. Use
isolated synthetic data for tests. Disclose AI assistance in the pull request
and verify generated changes before submitting them.

and logos retain their owners' rights.
